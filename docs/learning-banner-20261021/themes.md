# Additional banner themes

Owner brief, 22 October 2026 AEDT: create two more themes; the second may use a different creative direction, while the third must stick to the game's UI and art design.

The facts, feature availability notes and learning map are in [README.md](README.md). The new themes are promotional illustrations/compositions. Neither changes the game interface.

### Actual game references

- [Title screen](../../marketing/source/stills10/title-en.jpg): pink/purple lettering, white outline, lilac offset shadow, white panels and green Start button. Its old version label and loading text are not part of the banner.
- [Count With Me](../../marketing/source/stills10/game-count-en.jpg): flat fox icon, thick dark outline, rounded white answer buttons, small owl and blue/lilac gradient.
- [Rainbow Paints](../../marketing/source/stills10/game-colors-en.jpg): flat balloon and colour-choice cards. The banner example uses a purple balloon with the purple answer highlighted.
- [Music Corner](../r87/evidence/sound-ui/computer-music.png): the game's colourful musical keys and rounded controls.
- [Valley scenery](../../marketing/source/stills10/cine-hoian-en.jpg): simple low-poly world, faceted trees, roofs, lanterns and flowers.
- [Game stylesheet](../../css/style.css): pink `#ff6fae`, purple `#8a5cf6`, paper `#fff6e4`, Fredoka/Baloo 2 type and rounded control styling.

These are source references for a generated promotional composition. The banner previews arrange existing visual elements for communication; they are not a claim that the live game has this three-panel layout.

## Artwork review

Both new PNGs were visually inspected on 22 October 2026 AEDT. Theme 2 is 1672 × 941 pixels; theme 3 is 1672 × 940 pixels. The original remains available alongside them.

- Theme 2: all six headings, game examples, practice lines and parent/website copy checked for legibility and agreement with the brief.
- Theme 3: title treatment, gradient, owl, flat fox icons, rounded panels, colour swatches, musical keys and low-poly scene checked against the supplied game references. The counting example shows three foxes with 3 highlighted; the balloon and highlighted colour choice are both purple; the memory cards show a matching pair.
- All examples refer to existing activities. The banner makes no promise of guaranteed learning outcomes and does not present the unfinished drawing-game set as available.
